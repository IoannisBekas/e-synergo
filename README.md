# e_synergo Website

Static website for **e_synergo — ΣυνΕργώ Κέντρο Ειδικών Θεραπειών** (Acharnes, Greece).

🌐 **Live**: https://ioannisbekas.github.io/e-synergo/

## Stack

- **HTML/CSS/JS** — no framework
- **Tailwind CSS** — compiled locally (no CDN in production)
- **Sharp** — image optimization (PNG → WebP)
- **GitHub Pages** — hosting

## Pages

| File | Purpose |
|---|---|
| `index.html` | Home — hero, stats, services, about teaser, process, testimonials |
| `services.html` | 5 services + FAQ |
| `about.html` | Center info, team, values |
| `contact.html` | Form, map, contact details |
| `privacy.html` | GDPR privacy policy |
| `cookies.html` | Cookie policy |

## Local development

```bash
# Install dependencies
npm install

# One-time build (CSS + image optimization)
npm run build

# Watch mode (auto-rebuild CSS when HTML changes)
npm run watch:css

# Just rebuild CSS
npm run build:css

# Just optimize images
npm run optimize:images
```

Then open `index.html` in your browser (or use a static server).

## Configuration TODOs

### 1. Contact form (Formspree)

The contact form uses [Formspree](https://formspree.io). To activate:

1. Sign up at https://formspree.io (free tier = 50 submissions/month)
2. Create a new form and copy its endpoint URL
3. Edit `assets/script.js` — line 7:
   ```js
   const FORMSPREE_ENDPOINT = 'https://formspree.io/f/YOUR_ID';
   ```
4. Commit and push

Until then, the form shows a warning to call/email directly.

## Deployment

Pushed to GitHub → automatically deployed to GitHub Pages from `main` branch.

```bash
git add .
git commit -m "..."
git push
```

Allow ~1 minute for Pages to rebuild.

## Build outputs (committed)

These are generated by `npm run build` but committed to the repo so GitHub Pages can serve them:
- `assets/tailwind.css` (~26 KB minified)
- `assets/logo.webp`, `assets/BI Solutions.webp`

If you change HTML class names, **rerun `npm run build:css`** before committing — otherwise unused classes won't be purged and new ones won't be added.
